# folio-prism

个人投资组合管理 Android App。显示名：**资产配置**。当前版本：**0.4.0**。

用一个 App 替代现有的两套工具：

- invest-folio (私有 repo)：单文件 HTML 的实时估值 + 资产类别再平衡工具；
- [随手记](http://www.sui.com)：投资流水记账。

## 功能概览

### 理念

组合分为红利、成长、美股、美债、中债、黄金、现金 7 个大类别，每类设目标占比和允许区间。用户可自行设置规则参数，默认红利占 32%，其余六类平分非红利部分，默认区间为目标值的 ±10%。

**以资产类别再平衡为核心理念。** 日常关注各类别是否落在区间内，低于下限则买入，高于上限则卖出，把组合调回目标附近。7 类之外还可以设一个卫星类别，放不参与再平衡的主动仓位；卫星仓计入总资产，但不设目标和区间。

账本按事件记录：买入、卖出、基金转换、跨机构搬仓、换汇都归为转账事件，持仓由事件推导。分红按现金入账，不支持红利再投资；若实际进行了再投资，另录一笔买入。

### 适合的用户

- 按目标比例管理组合，重视投资纪律的个人投资者
- 资产分布在多个机构、标的、币种，需要合并查看
- 愿意逐笔录入交易，并能自行保证数据正确性

### 不适合的用户

- **试图预测市场的人**。这套工具的重心是长期配置比例，调仓按事先定好的区间执行，不预测行情
- **经常临时决定买卖的人**。强调投资纪律的重要性，反对情绪影响操作
- **不能坚持逐笔记录的人**。持仓、盈亏和曲线都从账本推算，如记录不完整，数据就不准确

### 功能和特性

- **事件账本**：按「机构 × 标的 × 7 大类」记录转账/买卖、现金分红/利息、外部出入金、支出、期初建仓与调整；自动记录转账损耗与手续费支出。
- **实时估值与再平衡**：首页一屏展示 7 大类的当前占比、目标值与区间条，红利/组合双口径统计；各类别给出再平衡阈值价；类别卡片可展开持仓明细，美元资产同时显示 USD 与 CNY 等值。
- **分析图表**：总资产曲线（可切换到任一类别，按「资金流 / 市场盈亏」拆分归因，可切换剔除资金流的净值曲线，可叠加出入金标记）、类别盈亏、投入取出、调仓统计、分红统计、机构/币种分布。
- **记账辅助**：单价按行情/手工价自动预填——只填空字段或仍保留上次建议的字段，手填后不再覆盖，清空后可重新填入，换标的后使用新标的报价；转账数量提供按价值与按目标占比的建议。
- **本地优先的数据**：数据固定保存在手机 `Documents/folio-prism/`，原子写入 + 滚动备份；App 关闭时也允许直接编辑 JSON。

另外，提供 **局域网 Web 工作台服务**：在设置页开启服务后，同一局域网内的电脑浏览器可直接访问手机内置的 Web 服务——查看带目标区间的资产概览与全部图表（含调仓/分红统计、资产曲线归因）、筛选并编辑流水（可追踪指定现金账户的逐笔余额）、下载/上传数据文件、上传新版 APK 到手机安装；修改会写回手机上的数据文件。页面与图表库完全内置，不依赖外网，无需在电脑上安装任何软件。该服务不做鉴权，仅适合在可信局域网内使用。

当前状态：核心功能可用，27 个测试类、228 个 JVM 单元测试覆盖计算、存储与 Web API。

## 数据存储

数据固定保存在：

```
/storage/emulated/0/Documents/folio-prism/
```

首次启动时若缺少「所有文件访问」权限，会跳转系统授权页。目录内维护：

```
folio-prism.json     主数据（账户、标的、事件、设置）
price-cache.json     历史价格缓存
backups/             带时间戳的自动备份（默认保留 5 份）
logs/                调试日志
```

备份通过手机系统文件管理器复制上述文件完成。App 不提供导入/导出 UI；允许在 App 关闭时直接手工编辑 JSON。

## 行情数据源

- 当前价格：沿用 `invest-folio` 的首选源（东财基金批量、腾讯 ETF/美股、东财 AU9999 / gold-api XAU、er-api 汇率），不使用备选源；首选失败即失败。
- 历史价格：东财 pingzhongdata（基金）、腾讯 kline（ETF/债券）、新浪财经美股日线、新浪上海金期货 AU0（作为 AU9999 历史的近似）。不抓取历史汇率；历史统计中的外币资产用当前汇率折算。
- 历史缓存只用于历史统计，不作为当前价格的 fallback。

## 构建与测试

本机工具链安装在用户目录（无需 root）：

```bash
export JAVA_HOME=$HOME/.local/opt/jdk-17
export ANDROID_HOME=$HOME/.local/share/android-sdk
export PATH=$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$PATH

# JVM 单元测试
./gradlew :app:testDebugUnitTest

# 构建 debug APK
./gradlew :app:assembleDebug

# 安装到已授权的手机
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
